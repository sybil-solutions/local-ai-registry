# RTX 5070 12GB: LFM3-1.7B NVFP4

Measured on the owner's Intel Core Ultra 9 285 (24 cores), 32 GB RAM, RTX 5070 12GB,
NVIDIA driver 620.70.06, Omarchy desktop on the same GPU. No power or clock changes.
Each server ran with a 12 GiB Docker memory cap and swap disabled, read-only weights,
and a localhost-only port mapping. Memory was sampled every 0.5 s with a watchdog.

`LiquidAI/LFM3-1.7B-NVFP4@cfe4b5eabe33e828256f760f72c0af600ceff0ad`.

## Image admission blocker

The recipe passes inference acceptance, but current `lab/image_trust.py` rejects a new
`vllm/vllm-openai` digest: no approved pinned builder. GitHub attestation verification
returns 404. Existing vLLM image pins are grandfathered; only the ROCm publisher has an
explicit exception. This contribution changes no policy, tests or allowlists. Maintainer
image admission or an approved rebuild is required before CI can pass. A different image
requires a new acceptance run.
