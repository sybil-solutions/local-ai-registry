# plugin/

What Omarchy Local AI reads. The paths are fixed: released plugins fetch them from `main` by name.

| File | Read by | State |
|---|---|---|
| `v3/recipes.json` | plugin 6.10 and later | current, generated by `lab/export_plugin.py` |
| `v2/recipes.json` | plugin 6.2 to 6.9, and `app/` (`make sync`) | current, generated by `lab/export_plugin.py` |
| `recipes.json` | plugin 5.x | frozen at 2026-09-25 (38 card kinds); not regenerated, kept so old installs still update |

CI fails if `v2/` or `v3/` drifts from the recipes (`python3 lab/export_plugin.py --check`).
