Probe annotation for these runs (2026-10-24, rx-7800-xt-16gb)
============================================================

`rx-7800-xt-16gb.20261024.probe.json` is the output of the kit's `tools/probe.py` (kit `ef9782c`), taken after the
first run on the same machine. Two things to know when reading it.

Why it was run through a wrapper
--------------------------------
The unmodified probe exits with `ValueError: not enough values to unpack (expected 8, got 1)` on this machine.
`nvidia-utils` is installed here as a dependency, and with no NVIDIA GPU `nvidia-smi` exits 9 and prints its
"couldn't communicate with the NVIDIA driver" message on stdout, which `gpus()` then parses as CSV. The file was
written by running `probe.py` unchanged, with one difference: a command that exits non-zero counts as absent.

Why `gpus` is empty
-------------------
`gpus()` only finds AMD cards through `rocm-smi`. Arch's `amdsmi` package (ROCm 7.2.4, what the plugin uses to detect
AMD cards) ships `amd-smi` but not `rocm-smi`, so the AMD branch finds nothing.

The container got only this card's render node (`--device /dev/dri/renderD128`, no `/dev/kfd`), so the iGPU in the
same machine (0000:11:00.0, gfx1036) was not visible to the engine.

How the runs were set up
------------------------
- Exact launch `llama.cpp-swift-1.5-qwen3.8-27b-iq3-s-mtp-128k` (image `@sha256:1086b881…`, argv unchanged; same
  `launch_sha256` as the rx-9070-xt-16gb proof). For runs 2 and 3, `docker inspect` returned the same 48 argv entries
  as `lab.py render`. Published on host port 18080 because 8080 is taken by another service here; the container port
  is the launch's 8080.
- Weights: `Swift-1.5-Qwen3.8-27B-GSQ-RCO-IQ3_S-mtp.gguf` at the pinned revision, 12,120,016,896 bytes, sha256
  9aecf1cd41b2cb2f32a74e0d889e33855ebef43b26f43b43feb5720239e677e5.
- Each run is a new container; `lab.py try --on endpoint` was the first client of runs 2 and 3. Run 1 answered
  three hand-sent chat requests before the gates.
- This card also drives the desktop (Hyprland, two monitors). The other GPU apps and a local LLM service were stopped
  first.

`mem_info_vram_used` / `mem_info_vram_total` (the kit's memwatch reads only `nvidia-smi`). One sample a second.
